# 📚 Repositorio de Laboratorios - ADSO

Este repositorio contiene el desarrollo de las prácticas y laboratorios correspondientes al programa de **Análisis y Desarrollo de Software (ADSO)** del SENA.

---

## 🛠️ Estructura y Ejecución de los Programas

Cada carpeta representa un laboratorio independiente desarrollado en Java. A continuación se detalla el contenido y las instrucciones para ejecutarlos.

### 1. `java-laboratorio-01` (Primeros pasos con Java)
* **Descripción:** Práctica inicial enfocada en la sintaxis básica de Java, uso de operadores aritméticos, manejo de estructuras de control y captura de datos por consola mediante la clase `Scanner`.
* **Cómo ejecutar el programa:**
  1. Abre la carpeta `java-laboratorio-01` en tu entorno de desarrollo (**Visual Studio Code**).
  2. Asegúrate de tener instalado el **JDK de Java**.
  3. Abre el archivo principal con extensión `.java` (ej. `Main.java` o el archivo correspondiente a la práctica).
  4. Ejecuta el archivo haciendo clic en el botón **Run** ( ▶️ ) de tu IDE o mediante la terminal ejecutando:
     ```bash
     javac NombreDelArchivo.java
     java NombreDelArchivo
     ```

---

### 2. `java-laboratorio-03`
* **Descripción:** Práctica centrada en la implementación de lógicas más avanzadas, validación de datos de entrada, manejo de excepciones y cálculos estructurados.
* **Cómo ejecutar el programa:**
  1. Abre la carpeta `java-laboratorio-03` en **Visual Studio Code**.
  2. Localiza el archivo ejecutable con el método `public static void main(String[] args)`.
  3. Ejecuta el programa desde la terminal o mediante el botón de ejecución del editor.

---

### 3. `Lab2`
* **Descripción:** Desarrollo correspondiente al segundo laboratorio, orientado a la estructuración modular del código y la resolución de problemas algorítmicos.
* **Cómo ejecutar el programa:**
  1. Carga la carpeta `Lab2` en tu espacio de trabajo de Visual Studio Code.
  2. Verifica que el archivo principal esté configurado correctamente.
  3. Compila y ejecuta la clase principal para visualizar el funcionamiento en la consola.
